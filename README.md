🏦 Telegram Payment Operations Bot
Профессиональный инструмент для автоматизации платежных операций и тестирования API

🎯 Цель проекта
Автоматизация рутинных задач инженера сопровождения платежных систем: проверка статусов операций, валидация банковских карт, работа с цифровыми подписями по стандартам СБП (Система быстрых платежей).

🚀 Основные возможности
1. Проверка статуса платежей ЕКОМ
Подключение к API Газпромбанка (PGA)

Поддержка тестового и боевых инстансов

Получение детальной информации о платежах по токену

Форматированный вывод в JSON с подсветкой

2. Валидация банковских карт (BIN Check)
Интеграция с APILayer BIN API, есть и с binchek.io(но там маленький лимит по апи)

Определение типа карты (Visa/Mastercard/МИР)

Информация о банке-эмитенте и стране

Проверка корректности BIN-номера

3. Валидатор цифровых подписей СБП
Генерация RSA-ключей (2048 бит, PEM-формат)

Формирование строк для подписи двумя методами:

Порядок следования полей (как в Swagger)

Алфавитный порядок полей (DATA alphabetical)

Подписание запросов алгоритмом SHA256withRSA

Верификация подписей с публичными ключами банка

Визуализация процесса формирования подписи

4. Безопасность и логирование
Экранирование HTML/спецсимволов

Структурированное логирование в файл

Валидация входных данных JSON

Безопасное хранение состояний пользователей

3. Запуск бота
